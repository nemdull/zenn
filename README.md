# Zenn 記事管理リポジトリ

## このリポジトリについて
- Zenn や Qiita へ投稿予定の技術記事の原稿と関連画像を管理するためのリポジトリです。
- 各記事ファイルは Front Matter（タイトル・emoji・topics など）を含む Markdown 形式で管理しています。
- `published: false` の記事は公開前のドラフトとして扱います。

## ディレクトリ構成
```text
.
└── articles
    ├── img/                       # 記事内で利用する画像
    ├── qiita-20220406-4ca51b8f9a2e814ed0a1.md
```
